# 负责任使用

[返回 README](../README.md) · [安全策略](../SECURITY.md) · [贡献指南](../CONTRIBUTING.md)

## 基本规则

只在你拥有或已获得明确书面授权的系统、账号、数据、网络和外部服务范围内使用本项目。源代码存在、可配置某个提供方或技术上能够发送请求，都不构成任何授权、资格、服务条款豁免、付款资格、数据处理权或第三方背书。

本项目的本地访问控制保护的是可信操作员边界，不会把未获授权的外部行为变为允许。

## 可以做的事

在授权范围内，你可以：

- 在隔离的本机环境阅读、构建、测试和改进源码；
- 使用虚构、测试或明确授权的资料验证本地 API、会话、配置和数据库行为；
- 审阅运行资料，发现疑似泄漏时停止并进行凭据轮换；
- 对自己管理的服务和账号执行已获批准的配置或维护工作；
- 以最少、已净化、不可用的示例报告文档或安全问题。

## 不可以做的事

不得使用本项目或其衍生内容：

- 未经授权创建、访问、控制、出售、共享或批量操作他人账号、身份资料、邮箱、电话号码、支付资料、会话或数据；
- 规避或协助规避 CAPTCHA、反自动化、访问控制、认证、地理/代理限制、付款限制、速率限制、服务条款或平台政策；
- 收集、拦截、保存、转发、发布或交易他人的 OTP、密码、令牌、cookie、邮箱内容、浏览器状态或个人数据；
- 将本地应用暴露为公开 API、公共 Webhook、代理、远程管理面板或多租户服务；
- 把真实凭据、配置、数据库、日志、截图、抓包或运行输出提交到仓库、Issue、聊天记录或发布资产；
- 声称本仓库获得任何第三方平台、邮件/短信/代理/支付供应商的认可、授权或合规保证。

## 停止条件

在以下任一情况出现时立即停止，不要通过技术手段“继续尝试”：

1. 无法确认书面授权、数据来源或账号控制权；
2. 请求涉及他人的资料、第三方生产系统或公共网络边界；
3. 外部服务拒绝、限制或要求额外验证；
4. 发现真实秘密、会话、OTP、数据库或浏览器状态可能已泄漏；
5. 操作会绕开安全控制、合同、适用法律或服务政策。

先隔离本地资料，撤销或轮换受影响凭据，并在不含敏感材料的前提下寻求授权方或维护者的指引。安全漏洞细节遵循[安全策略](../SECURITY.md)：在目标仓库启用可验证的私密报告通道前，不要公开披露。

## 贡献和审阅

贡献者不得提交扩大网络边界、降低 TLS/认证/CSRF 保护、绕过服务控制或使用真实第三方资料的功能、测试和教程。维护者应拒绝无法证明来源、授权和可再分发权利的贡献。详见[贡献指南](../CONTRIBUTING.md)与[行为准则](../CODE_OF_CONDUCT.md)。
