## Interpretation (evidence-based)

1. **Protocol path itself is still green** when not challenged: 3 workers completed S0→S14 with token_len ≈ 1752–1760 in ~33–46s (same ballpark as serial).
2. **Dominant parallel failure = real CF on authorize (S4)**, not classifier false-positive (status=403 + `cf-mitigated`).
3. Single bestgo **seed row** with distinct SIDs still shares vendor pool / ASN reputation → concurrent authorize hits get mitigated.
4. Secondary failures (OTP / S11 / S12) look like load or mailbox/Graph jitter under burst — not the serial path bugs already fixed.
